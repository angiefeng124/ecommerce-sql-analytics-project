# E-Commerce Analytics Project using SQL Server

## Overview

This project analyzes sales transactions, customer behavior,
and product performance using SQL Server.

The project builds an analytical database layer and creates
business reports to answer key sales questions.

## Tools

- SQL Server
- T-SQL
- Docker
- Tableau
- GitHub


## Skills Demonstrated

- CTEs
- Window Functions
- Aggregations
- Views
- Data Modeling
- Business Reporting


## Project Structure

Bronze Layer:
Raw sales data

Silver Layer:
Cleaned and transformed data

Gold Layer:
Business-ready views for analytics


## Key Analysis

- Revenue trends over time
- Customer segmentation
- Product performance
- Sales growth analysis
